# ADR-005. Обнаружение Storage Node по составу Raft

## Решение

CP API публикует Prometheus HTTP SD на существующем HTTP-порту. Каждая
наблюдаемая область получает полный список целей. Профиль с двумя регионами
запрашивает каждый регион отдельно, поэтому неизвестный состав одного региона
не блокирует обновление целей другого.

Источником служит применённый состав, который сообщает лидер. StateStore
проверяет регион, партицию, инкарнацию группы, личность голосующего лидера
и порядок Raft configuration index. Discovery использует участников из
последнего принятого снимка целиком, включая learner и выходящих голосующих
участников joint configuration. Heartbeat и готовность маршрута определяют
свежесть снимка. Таймаут heartbeat, выборы и потеря кворума сохраняют
последний состав. Gateway использует своё представление готовых реплик.

В профиле с MemoryStore CP атомарно сохраняет применённый состав в локальный
чекпоинт при изменении configuration index. Чекпоинт переживает перезапуск CP.
Первый запуск с новым путём может использовать явные bootstrap-адреса.
При повторном запуске CP отвечает 503 для областей с неизвестным составом
до получения отчётов от Raft. Файл рассчитан на один экземпляр CP.
Реализация StateStore с общим хранилищем сможет восстановить тот же снимок
из него. [Контракт HTTP SD](https://prometheus.io/docs/prometheus/latest/http_sd/).

## Граница доверия

`raft_address` задаётся оператором через bootstrap-конфиг или API управления
составом. CP публикует только HTTP(S) с корректным DNS-именем или IP и портом
1–65535. При отсутствии порта используется стандартный порт схемы.
Адреса без назначения, multicast и link-local IP, credentials и fragment
отклоняются. Путь сбора фиксирован как `/metrics`, параметры Raft URL
отбрасываются.
Prometheus не следует HTTP-редиректам для этих целей.

Текущие gRPC heartbeat и API управления составом доступны в доверенной сети.
Развёртывание должно ограничивать доступ к ним Storage Node и операторами,
доступ к discovery — системой мониторинга, а исходящие соединения Prometheus —
сетями и портами Storage Node. DNS-имена должны принадлежать этой сети.
Проверка формата адреса не проверяет владение хостом. CP публикует адреса,
а соединения открывает Prometheus.
