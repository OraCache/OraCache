Выполняйте все команды **из корня проекта**. Вставляйте блоки по очереди и сверяйте результат каждого шага. Сценарии используют порты Compose по умолчанию, поэтому перед следующим сценарием остановите текущий стенд.

Для Compose-сценариев нужны Docker Engine, Docker Compose, `make`, Go 1.27.3 или новее и `curl`. Дополнительные инструменты указаны в соответствующих шагах. Для `go test -race` нужны cgo и C-компилятор.

`make build` собирает бинарники в `bin/`. Клиентские команды используют `./bin/oracache`. Отчёты и тестовые данные сохраняются в `.reports/` в тех сценариях, где они нужны.

Префикс `env ORACACHE_ENDPOINT=...` задаёт адрес только для одного вызова. Доменные статусы `MISS` и `CONFLICT` приходят в JSON при успешном gRPC-вызове. Поля `rev` и `latestRev` представлены строками, а `data` кодируется в Base64.
