# Публикуемый состав

Ветка содержит нейтральные архитектурные документы, ADR/RFC и индекс непрозрачных evidence ID. Частные переписки, записи встреч, точные частные локаторы, provenance, инструменты извлечения и отчёты с частными локаторами в Git не включены. [Отчёт о технических проверках PoC](experiments/static-leader-verification.md) входит в пакет: он связывает результаты с версиями кода и запусками CI.

Разрешение владельца распространяется на отдельную ветку документации. Оно не означает принятия всех открытых RFC или разрешения публиковать исходные частные материалы. Новые технические решения и выполненные проверки должны обозначаться отдельно от исторических свидетельств.
