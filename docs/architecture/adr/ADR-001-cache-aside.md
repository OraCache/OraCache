# ADR-001: приложение заполняет кэш после MISS

Статус: принятое продуктовое решение, 13.10.2026. Область: обычный доступ приложения к данным target; эта же модель используется в PoC. Основание E-001.

## Контекст

Кэш хранит только часть данных основной БД. При запросе отсутствующего ключа нужно определить, кто загрузит значение из источника и как приложение узнает об отсутствии данных. В раннем обсуждении рассматривалось самостоятельное обращение кэша в БД. Предметный итог обсуждения закрепляет ответственность за обычную загрузку у приложения.

## Решение

Использовать cache-aside. Приложение выполняет Get и различает HIT, когда значение найдено, и MISS, когда его нет. [После MISS приложение читает БД и вызывает Put](../REQUIREMENTS.md#r-001). Обычный Get сервиса кэша не выполняет скрытый запрос к БД.

## Основания и последствия

Такой контракт сохраняет у приложения знание источника и способа чтения данных. Сервису кэша не нужен доступ к БД для каждого отсутствующего ключа. Приложение при этом отвечает за обработку MISS и ошибки БД.

Для сравнения: read-through передал бы обычную загрузку самому кэшу, потребовав интерфейса источника, доступа и правил обработки его отказов. Это анализ следствий альтернативы; источники не дают оснований приписывать весь этот перечень историческим мотивам команды.

Cache-aside допускает задержанное заполнение: приложение может прочитать БД до чужого обновления и записать результат в кэш после него. Решение не определяет [протокол защиты от такой гонки](../REQUIREMENTS.md#r-009). Он рассматривается в [RFC-001](../rfc/RFC-001-api.md).

## Незакрытые детали и подтверждение

В target отдельно требуется [массовый прогрев после холодного старта](../REQUIREMENTS.md#r-017). Источник, формат и readiness прогрева выбираются в [RFC-003](../rfc/RFC-003-recovery.md); этот ADR задаёт только обычный путь доступа.

Проверка соответствия: после MISS запрос к БД делает приложение, а обычный Get кэша возвращает результат без скрытой загрузки. Наличие PoC не означает выполнения всех будущих критериев свежести и прогрева.
